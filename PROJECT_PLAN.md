# Merishaw Schools Website Rebuild Project Plan

## Project Goals

- Rebuild the Merishaw Schools website as a modern, premium, mobile-first school website using Next.js, TypeScript, Tailwind CSS, and Framer Motion.
- Preserve verified content from the existing website and clearly mark missing content that requires client approval.
- Create a professional brand system based on the official Merishaw School logo and current website colors.
- Deliver reusable components, clean data files, SEO metadata, accessible navigation, responsive layouts, and deployment-ready build output.

## 7-Day Timeline

### Day 1: Content Audit and Setup

- Audit existing website pages, downloads, images, gallery assets, contact details, and old navigation.
- Create planning documentation: project plan, content audit, brand guide, page structure, and TODO tracker.
- Scaffold the Next.js project and configure TypeScript, Tailwind CSS, Framer Motion, and base SEO metadata.

### Day 2: Homepage and Layout

- Build the global layout, responsive navbar, footer, buttons, section headings, page headers, cards, and CTA components.
- Build the homepage hero, school summary, academics preview, pillars preview, admissions CTA, leadership preview, gallery preview, support-a-child CTA, downloads preview, and contact preview.

### Day 3: About, Academics, and Leadership

- Build About with verified school overview, mission, vision, values, facilities, architectural concept, and leadership messages.
- Build Academics with 8.4.4, CBE, pathways, competencies, and pillars content.
- Build Leadership with principal, director/founder note, and student council content.

### Day 4: Admissions, Downloads, and Support a Child

- Build Admissions using verified form fields and clear placeholders for missing application-process content.
- Build Fees Structure / Downloads with current fee PDF and existing Google Drive links.
- Build Support a Child using verified CSR themes and marked sponsorship copy pending client approval.

### Day 5: Gallery, News, Contact, and SEO

- Build Gallery using migrated old website image assets and video links.
- Build News / Updates using the verified STEM and Lacrosse stories.
- Build Contact with validated form behavior, contact details, social links, and map section.
- Add page-level metadata for all routes.

### Day 6: Responsive QA, Accessibility, and Performance

- Test mobile, tablet, and desktop layouts.
- Verify navigation, CTAs, form behavior, download links, image rendering, semantic headings, color contrast, keyboard access, and reduced-motion behavior.
- Run lint, typecheck, and production build.

### Day 7: Deployment Preparation

- Add deployment notes for Contabo VPS + Coolify.
- Document environment variables and production build commands.
- Final QA pass and handoff checklist.

## Phases

### Phase 1: Content Audit and Setup

Create the documentation files, scaffold the project, mirror useful assets, and configure the design system.

### Phase 2: Homepage and Layout

Build reusable layout primitives and the complete homepage experience.

### Phase 3: Internal Pages

Build About, Academics, Admissions, Leadership, Gallery, Downloads, Support a Child, News, and Contact.

### Phase 4: Polish, SEO, and Testing

Add metadata, responsive refinements, Framer Motion polish, accessibility checks, and production validation.

### Phase 5: Deployment Preparation

Prepare Coolify deployment instructions, production environment notes, and final handoff documentation.
